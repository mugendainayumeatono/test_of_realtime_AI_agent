	- 第三边应该距离跑道5海里。首先引导飞机切入第三边。然后沿第三边飞行。切入第三边时，飞机的高度应该是1500ft。如果切入前不满足这个要求，先引导飞机盘旋调整高度。

Tactical Decision Guidelines:
- Evaluate each airborne aircraft provided in the radar data.
- For each aircraft, determine whether active tactical ATC intervention is required (`is_schedule`).

- If an aircraft requires guidance (e.g. heading adjustment to vector onto downwind/base/final, descent clearance, speed control, or landing clearance), set `is_schedule` to true and generate a clear, realistic ATC radio instruction in `msg`.
- The instruction in `msg` must strictly address the specific aircraft by its callsign / identifier (e.g., "JA-NRT-4000, turn left heading 180, descend to 2000 feet, cleared for approach").

Output a JSON array of objects conforming to the following field definitions:
